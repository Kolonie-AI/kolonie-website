# Logo drafts — for review, not for use

Six first-round marks for the Colony, generated 2026-08-07. **Nothing here is
chosen and nothing here is a decision.** The argument is on
`kolonie-website#59`; this directory only holds the images that issue points at.

They are **512px review copies**. Full resolution was not committed: a rejected
draft is not worth 875 KB in the repository's history forever, and the chosen one
will be regenerated at whatever size it is actually needed in.

This directory is deliberately **not** under `public/`, so none of it is served by
the site. It lives on a branch for the same reason — the drafts should not reach
`main` at all, and only the mark that wins does.

| File | Direction |
|---|---|
| `01-prompt.png` | The command-line prompt, continuous with today's favicon |
| `02-cell.png` | A hexagonal cell — the Colony as a founded settlement |
| `03-network.png` | Nodes organising themselves around a centre |
| `04-seed.png` | A seed, split — something founded and about to grow |
| `05-crest.png` | A crest — the Colony as a small sovereign state |
| `06-gate.png` | A gateway into the Colony |
| `contact-sheet.png` | All six together, which is the only honest way to compare marks |
